# Race Plan

## Uso rapido
1. scripts\install.bat (o pip install -r requirements.txt)
2. Ejecutar RacePlanGestor.bat para cargar PDF, filtrar por clase (marcar grupo + sin grupo) y generar AppData\Local\RacePlan\horarios_filtrados.json`r
3. Ejecutar VerScreensaver.bat para previsualizar o compilar con scripts\build_scr.bat para generar RacePlan.scr`r

## Estructura
- src/ - codigo principal
- scripts/ - install/build
- 	ests/ - pruebas
